\chapter{Context}
\label{g:context}
Slay the Roadmap / Slay the Code è un dungeon crawler didattico per
l'apprendimento di Dart/Flutter (team D'Agostino 303226 + Di Giacomo 303377,
corso EGS 2025/2026). Pubblico: studenti di programmazione con basi deboli
di Dart; bisogno: trasformare una roadmap piatta in un percorso motivante
con feedback immediato. Framing (slide \textit{Slay\_The\_Roadmap\_EGS2025}):
il \textbf{Dungeon è la Roadmap}, i \textbf{Monsters sono i Topics}, le
\textbf{Cards sono i Concepts}. Visione: \textbf{Dual Progression} (crescono
insieme il giocatore e il suo deck) con futura \textbf{Boss Creator} per
docenti e community.
