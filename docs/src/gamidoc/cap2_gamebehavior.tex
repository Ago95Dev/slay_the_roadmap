\chapter{Game behavior}
\label{g:behavior}
Il core loop, con durate dal GamiDOC di riferimento
(\textit{gamidoc\_5}):

\begin{enumerate}
\item \textbf{Studio} (6--8\,min): pagina topic con link opzionali.
\item \textbf{Quiz} (3--5 domande, soglia 80\%, tentativi illimitati ma
penalizzati): superarlo sblocca il topic successivo + 1 carta.
\item \textbf{Deck} (2--3 carte per sessione): scelta e combinazione carte.
\item \textbf{Boss} (10--15\,min): turni alterni carte/quiz contro Gargoyle
(150\,HP), StackOverflow (200\,HP), Async, WidgetTitan (250\,HP).
\end{enumerate}

Regole numeriche: energia minima 3 per giocare, 3 vite; carte Common 6,
Rare 10, Epic 16 + Perf 5, Legendary 25 + Crit 25\%; soglie boss 25/50/75\%
con cambio pattern. Mockup M1--M7 (\texttt{docs/legacy/3\_Mockups.pdf}) fissano le
schermate: Home, Pick a PATH, Roadmap (99\,XP, vite 3/5, energia 5/5),
Topic, Boss carte/quiz, Deck (Level 12 Rogue, Energy 4, 6+2 carte, 2+2 skill).
