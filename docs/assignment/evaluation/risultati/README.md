# Risultati — LEGGERE PRIMA

Questa cartella contiene UN file per utente (U1..U5) con i campi da
compilare DURANTE/ DOPO sessioni reali.

REGOLA NON NEGOZIABILE: qui vanno solo dati di sessioni veramente
svolte. Inventare utenti, tempi o punteggi e consegnarli come veri
è falsificazione dei dati d'esame: invalida la valutazione e, se
scoperta, anche il resto del lavoro. I campi restano vuoti finché
la sessione non avviene.
