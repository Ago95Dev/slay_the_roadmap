# User Stories + Sprint 1

Fonti: `docs/legacy/EGS_assignment2_From User Stories to Sprint 1 Prototype.pdf` + file `docs/legacy/user_stories`.

## User Stories

| ID | Come … voglio … per … | Criteri di accettazione (breve) |
|----|-----------------------|---------------------------------|
| US-01 | Come nuovo giocatore, vedere la roadmap ad albero per capire percorso e prerequisiti | Topic con indentazione; stato bloccato/in corso/completato; highlight opzionali vs obbligatori; click-to-expand |
| US-02 | Come giocatore, completare un topic con quiz per sbloccare il prossimo e guadagnare ricompense | Quiz 3–5 domande; soglia 80%; feedback immediato; badge; sblocco automatico |
| US-03 | Come giocatore, scegliere 1 ricompensa per topic per personalizzare lo stile boss fight | Tipi diversi; preview effetto; inventory visibile; limite 1 per topic |
| US-04 | Come giocatore, affrontare il boss di capitolo con quiz adattivi per testare le conoscenze | HP boss; turno carte / turno quiz; soglie 25/50/75%; vittoria/sconfitta con conseguenze |
| US-05 | Come giocatore, avere persistenza automatica per riprendere da dove ho lasciato | Salvataggio topic/deck/boss; recupero all'avvio; reset opzionale |

## Sprint 1

- Dentro: US-01 (P5/M), US-02 (P5/L), US-03 (P4/M).
- Fuori: US-04, US-05 (boss solo prototipo locale, persistenza in memoria).
